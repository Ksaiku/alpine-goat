# ALPINE GOAT

リアルなヤギを主人公にした、ブラウザで遊べる横スクロールアクションゲーム。

## 遊ぶ

**https://ksaiku.github.io/alpine-goat/**

ブラウザで開くだけで遊べます。インストール不要。スマホにも対応しています。

## 操作方法

| 動作 | キーボード | タッチ |
|---|---|---|
| 左右移動 | `←` `→` / `A` `D` | 画面左下の方向パッド |
| ジャンプ | `Space` / `↑` / `W` | 画面右下 A ボタン |
| 頭突き（ダッシュ突進） | `Shift` / `J` | 画面右下 B ボタン |
| ポーズ | `Esc` / `P` | 画面右上 ボタン |
| 決定（メニュー） | `Space` / `Enter` | タップ |

- ジャンプは1段のみ（二段ジャンプなし）。
- タッチUIはタッチ入力を検知したときだけ表示されます（PCでは非表示）。

## ゲームの内容

- 全3ステージ（山麓の斜面 / 氷穴 / 山頂への道）
- 1発死。ただしチェックポイントから何度でも復帰できる
- 敵は3種類（マーモット / ワシ / ヤマアラシ）
- **ヤマアラシは踏むと死ぬので、頭突きで倒すこと**
- タイムと死亡回数が記録され、ブラウザに保存される

## 技術的な特徴

- **画像ファイルを1枚も使っていない。** ヤギ・敵・地形・背景のすべてを Canvas のパス描画で生成している
- ヤギは関節を持つ骨格として実装され、足を置く位置から膝の角度を逆算している（そのため、走る速度に応じて歩幅と歩数が変わり、接地した足は地面を滑らない）
- 外部ライブラリを一切使っていない（Vanilla JavaScript + Canvas 2D のみ）。ビルド作業も不要
- 固定タイムステップで物理を更新しているため、フレームレートが変動しても挙動が変わらない

## ローカルで動かす

ES Modules を使っているため、HTTPサーバー経由で開く必要があります。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

> ソースを編集しても変更が反映されないときは、ブラウザの強制リロード（`Ctrl` + `Shift` + `R`）を試してください。
> `python -m http.server` はキャッシュ制御のヘッダーを返さないため、ブラウザが古いファイルを使い回すことがあります。

## ファイル構成

```
side-scroller-game/
├── index.html          エントリHTML（canvas を1枚置くだけ）
├── style.css           レターボックス表示のスタイル
├── SPEC.md             仕様書
├── TASKS.md            実装工程の分解表
├── README.md           このファイル
├── prompts/            実装担当への依頼プロンプト
└── src/
    ├── main.js          エントリポイント / ゲームループ / 画面遷移
    ├── config.js        全パラメータ定数
    ├── input.js         キーボード + タッチ入力
    ├── goat.js          ヤギの状態機械と物理
    ├── goatRenderer.js  ヤギのプロシージャル描画（関節駆動）
    ├── world.js         地形データの解釈と衝突判定
    ├── camera.js        カメラ追従
    ├── background.js    パララックス背景（alpine / cave / summit）
    ├── enemies.js       敵の挙動と描画
    ├── hud.js           HUD / メニュー画面
    ├── storage.js       localStorage への進捗保存
    └── stages/
        ├── stage1.js    山麓の斜面
        ├── stage2.js    氷穴
        └── stage3.js    山頂への道
```
