# 作業A（先に必ずこれを直すこと）— フォーカス喪失によるキー固着バグの修正

## 発見された不具合

`→` を押しながら別のウィンドウやタブに切り替えると、**`keyup` がページに届かないため、そのキーが押されっぱなしの状態で残ります。**
戻ってきたとき、何も押していないのにキャラクターが走り続けます。

実測で再現確認済み: `ArrowRight` を押下したまま `blur` を発生させたところ、その後も `IN: right` の表示が消えず、x 座標が 166 → 226 と増え続けました。

Phase 3 で重力とジャンプが入ると、この不具合は「操作していないのに勝手に走って穴に落ちる」という致命的な症状になります。**先に直してください。**

## 修正内容（`src/input.js`）

1. 全アクションの押下状態を解除する内部関数 `clearAll()` を追加する。
   - 全アクションについて `kbHeld` と `touchHeld` を `false` にし、各アクションに対して既存の `recompute()` を呼ぶ。
   - `recompute()` を経由することで、押されていたアクションには `wasReleased` が正しく立ちます。**この経路を必ず使ってください**（直接 `combined` を書き換えないこと）。後続フェーズの「ジャンプキーを離すと上昇が止まる」処理が `wasReleased` を見るためです。

2. `init()` の中で以下の2つを登録する。
   ```js
   window.addEventListener('blur', clearAll);
   document.addEventListener('visibilitychange', () => {
     if (document.hidden) clearAll();
   });
   ```

3. **確認方法:** `→` を押しながら別ウィンドウをクリックし、戻ってきたときに `IN: -` になっていて矩形が止まっていること。

## 2. `src/goat.js` の仕様

### 公開するもの

`Goat` クラスを `export` する（`export class Goat { ... }`）。

### コンストラクタ

`constructor(x, y)` — 引数は当たり判定矩形の**左上の座標**。

### プロパティ（この名前で必ず持つこと）

| 名前 | 内容 |
|---|---|
| `x`, `y` | 当たり判定矩形の左上座標 |
| `width`, `height` | `GOAT_HITBOX_WIDTH` / `GOAT_HITBOX_HEIGHT` |
| `vx`, `vy` | 速度（px/秒）。上向きが負 |
| `onGround` | 接地しているか（boolean） |
| `facing` | 向き。右が `1`、左が `-1` |
| `state` | 状態名の文字列。`'idle'` / `'walk'` / `'run'` / `'jump'` / `'fall'` のいずれか |
| `coyoteTimer` | 地面を離れてからのジャンプ猶予の残り（秒） |
| `jumpBufferTimer` | 先行入力の残り（秒） |

### メソッド

- `update(dt)` — 物理と状態の更新
- `render(ctx)` — 描画（Phase 3 では暫定の矩形）

### ★ `update(dt)` の処理順序（この順番で実装すること。順番が変わると挙動が変わります）

**1. タイマーを減らす**
```
coyoteTimer     = Math.max(0, coyoteTimer - dt)
jumpBufferTimer = Math.max(0, jumpBufferTimer - dt)
```

**2. 水平入力から vx を更新する**
- `dir = (右が押されていれば +1) + (左が押されていれば -1)`（両方押しなら 0）
- `dir !== 0` のとき:
  - 加速度は接地中なら `ACCEL_GROUND`、空中なら `ACCEL_AIR`
  - `vx += dir * 加速度 * dt`
  - `vx` を `-MOVE_SPEED` 〜 `+MOVE_SPEED` の範囲に収める
- `dir === 0` かつ **接地中**のとき: `FRICTION_GROUND * dt` の分だけ `vx` を 0 に近づける（**0 を通り越して逆向きにならないよう必ず 0 で止めること**）
- `dir === 0` かつ **空中**のとき: **何もしない**（慣性を残す。空中で急停止すると操作感が悪くなるため）

**3. ジャンプ入力を処理する**
- `Input.wasPressed('jump')` なら `jumpBufferTimer = JUMP_BUFFER_TIME`
- **ジャンプ成立条件: `jumpBufferTimer > 0` かつ `coyoteTimer > 0`**
  成立したら:
  ```
  vy = JUMP_VELOCITY
  jumpBufferTimer = 0
  coyoteTimer = 0
  onGround = false
  ```
- `Input.wasReleased('jump')` かつ `vy < 0`（上昇中）なら `vy *= JUMP_CUT_MULTIPLIER`
  （＝キーを短く押すと低く、長く押すと高く跳ぶ）

**4. 重力を適用する**
```
vy += GRAVITY * dt
if (vy > MAX_FALL_SPEED) vy = MAX_FALL_SPEED
```

**5. 位置を更新する**
```
x += vx * dt
y += vy * dt
```

**6. 仮の地面との衝突を解決し、`onGround` を確定する**
```
if (y + height >= TEMP_GROUND_Y) {
  y = TEMP_GROUND_Y - height
  vy = 0
  onGround = true
} else {
  onGround = false
}
```
また、`x` を `0` 〜 `LOGICAL_WIDTH - width` にクランプし、壁にぶつかったら `vx = 0` にする。

**7. 接地していれば猶予タイマーを満タンにする**
```
if (onGround) coyoteTimer = COYOTE_TIME
```
（**必ず手順6の後に行うこと。** 先に行うと、地面を離れた瞬間に猶予が消えてしまいます）

**8. 向きと状態を更新する**
- `facing`: `vx > 0` なら `1`、`vx < 0` なら `-1`、`vx === 0` なら**前の値を維持**する
- `state` の判定（上から順に評価する）:

| 条件 | state |
|---|---|
| 接地していない かつ `vy < 0` | `'jump'` |
| 接地していない | `'fall'` |
| `Math.abs(vx) < 10` | `'idle'` |
| `Math.abs(vx) < MOVE_SPEED * 0.6` | `'walk'` |
| それ以外 | `'run'` |

### `render(ctx)` の仕様（Phase 3 の暫定表示）

**ヤギの本描画は Phase 6 の担当です。ここでは向きが分かる程度の暫定表示にとどめてください。**

- 当たり判定矩形を茶色 `#8b5e3c` で塗る。
- **向きが分かるように**、`facing` 側の上部に、幅16px・高さ14pxの濃い茶色 `#5c3a22` の矩形を「頭」として描く。
  （`facing === 1` なら矩形の右上、`facing === -1` なら左上）
- 全体を `ctx.save()` / `ctx.restore()` で囲む。

## 3. `src/main.js` の変更

1. `placeholder` オブジェクトと、それに関する `update` 内の移動処理を**削除**する。
2. 代わりに `const goat = new Goat(100, TEMP_GROUND_Y - GOAT_HITBOX_HEIGHT);` を生成する。
3. `update(dt)` では `goat.update(dt)` を呼ぶ。ジャンプ／頭突きの累計カウントは残す。
4. `render()` では地面の描画のあとに `goat.render(ctx)` を呼ぶ。
5. デバッグ表示を以下に変更する（`DEBUG === true` のとき）:
   ```
   FPS: <平均fps>
   DPR: <dpr>
   IN: <押下中のアクション>
   state: <goat.state>   ground: <true/false>   facing: <1 or -1>
   pos: <x整数>, <y整数>
   vel: <vx整数>, <vy整数>
   coyote: <小数2位>   buffer: <小数2位>
   peak: <直近のジャンプで到達した最高の高さ(px)を整数で>
   ```
   - `peak` は「ジャンプ開始時の y」と「そのジャンプ中に到達した最小の y」の差。**着地するまで値を保持し、次のジャンプで更新する。** これはジャンプの高さが仕様どおり（約131px）かを検証するための表示です。
