```

```

### A-2. `src/goat.js` の突進終了処理

```js

| 突進が終わった状況 | 次に撃てるまで |

```

## D-2. `src/goat.js` の変更

### 追加するプロパティ

| プロパティ | 初期値 | 意味 |
|---|---|---|
| `isDead` | `false` | 死亡演出中か |
| `deathTimer` | `0` | 死亡演出の残り時間（秒） |
| `deathRotation` | `0` | 死亡中の回転角（ラジアン） |
| `invincibleTimer` | `0` | 無敵の残り時間（秒） |

### `die()` メソッドを追加

```js
die() {
  if (this.isDead) return;        // 二重に死なない
  this.isDead = true;
  this.deathTimer = DEATH_ANIM_TIME;
  this.deathRotation = 0;
  this.vx = 0;
  this.vy = DEATH_JUMP_VELOCITY;  // 上へ跳ねる
  this.isDashing = false;
  this.state = 'dead';
}
```

### `update(dt, world)` の先頭で分岐する

**`isDead` が `true` のときは、通常の処理を一切行わず、死亡演出だけを進めること。**

```js
if (this.isDead) {
  this.deathTimer = Math.max(0, this.deathTimer - dt);
  this.deathRotation += DEATH_SPIN_SPEED * dt;
  this.vy = Math.min(MAX_FALL_SPEED, this.vy + GRAVITY * dt);
  this.y += this.vy * dt;         // ★地形を無視してそのまま落ちる
  this.state = 'dead';
  return;                          // 入力・衝突・棘の判定は一切行わない
}
```

**地形との衝突を無視するのが重要です。** 死体が床の上で止まると、演出が「跳ねて落ちる」ではなく「跳ねて着地」になってしまいます。

### 無敵タイマーの減算

手順1（タイマー減算）に追加する。

```js
this.invincibleTimer = Math.max(0, this.invincibleTimer - dt);
```

### `respawn(x, y)` メソッドを追加

```js
respawn(x, y) {
  this.x = x;  this.y = y;
  this.vx = 0; this.vy = 0;
  this.isDead = false;
  this.deathTimer = 0;
  this.deathRotation = 0;
  this.isDashing = false;
  this.dashTimer = 0;
  this.dashCooldown = 0;
  this.invincibleTimer = INVINCIBLE_TIME;
  this.state = 'idle';
  this.phase = 0;
}
```

## D-3. `src/enemies.js` の変更

`resolveGoatEnemyCollisions` の判定に、次を加える。

- **`goat.isDead === true` のときは、何も判定せず即 `return`** する（死亡演出中は当たらない）
- **「それ以外は被弾」の分岐で、`goat.invincibleTimer > 0` のときは `onGoatHit()` を呼ばない**（すり抜ける）

**踏みつけと突進による撃破は、無敵中でも通常どおり成立させること。** 無敵は「ダメージを受けない」だけで、攻撃はできます。

## D-4. `src/goatRenderer.js` の変更

### (a) 無敵中の点滅

描画関数の**先頭**で次を判定し、点滅の「消える側」なら何も描かずに `return` する。

```js
if (goat.invincibleTimer > 0 &&
    Math.floor(goat.invincibleTimer * BLINK_RATE) % 2 === 1) {
  return;
}
```

**`ctx.save()` を呼ぶ前に return すること**（save したまま抜けると ctx の状態が壊れます）。

### (b) 死亡中の回転

`goat.isDead === true` のとき:

- **姿勢は `fall`（落下）と同じもの**を使う
- 座標変換のあと、**胴体の中心（`0, -32`）を軸に `goat.deathRotation` だけ回転させる**
  ```js
  ctx.translate(0, -32);
  ctx.rotate(goat.deathRotation);
  ctx.translate(0, 32);
  ```
- **スピードラインは描かない**

## D-5. `src/main.js` の変更

### (a) 復帰地点を保持する

let respawnX = stage1.spawn.col * TILE_SIZE;

### (b) `killGoat()` 関数を作る

```js
// ヤギを死亡させる（死亡演出つき）。死因は敵・棘の2つ
function killGoat() {
  if (goat.isDead || goat.invincibleTimer > 0) return;
  goat.die();
  deaths++;
}
```

### (d) `update(dt)` の処理順序

**この順序で実装すること。**

```

3. 死亡していないときの処理:
   ・落下判定: goat.y > world.heightPx + TEMP_FALL_LIMIT なら
       deaths++ して即 respawnGoat()（★落下は死亡演出を出さない。画面外なので見えないため）
   ・棘判定: goat.touchingSpike なら killGoat()
   ・敵の更新
   ・resolveGoatEnemyCollisions(goat, enemies, world, killGoat)
       ★コールバックを respawnGoat から killGoat に変更する
   ・倒された敵を配列から取り除く
   ・チェックポイント判定:
       const cp = world.checkCheckpoints(goat);
       if (cp) { respawnX = cp.x + (TILE_SIZE - GOAT_HITBOX_WIDTH) / 2;
                 respawnY = (cp.row + 1) * TILE_SIZE - GOAT_HITBOX_HEIGHT; }

4. world.update(dt)
5. camera.follow(goat, dt)
```
