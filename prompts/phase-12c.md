# 作業B — 縦画面のときに「横向きにしてください」と案内する

## なぜ必要か

このゲームは**16:9の横長**を前提に作られています。スマホを縦に持って開くと、
画面の上下に大きな黒い帯が出て、**ゲーム画面が細長い帯になり、仮想パッドも押しづらくなります。**

公開URLを人に共有したとき、**大半の人はスマホで、しかも縦持ちで開きます。**
「変なものが表示された」で終わらせないために、案内を出します。

## B-1. `src/hud.js` に `drawRotateNotice(ctx)` を追加して `export` する

- **画面全体を `UI_PANEL` で塗りつぶす**（ゲーム画面を完全に隠す）
- 中央に、上から順に次を**中央揃え**で描く

| 内容 | サイズ | 色 |
|---|---|---|
| `📱` | 48px | `UI_TEXT` |
| `画面を横向きにしてください` | 24px | `UI_TEXT` |
| `このゲームは横画面用です` | 15px | `UI_TEXT_DIM` |

- **全体を `ctx.save()` / `ctx.restore()` で囲むこと**

## B-2. `src/main.js` で縦画面を検出する

1. 縦画面かどうかを保持する変数を用意する。

   ```js
   // ウィンドウが縦長のとき true。スマホの縦持ちを想定
   let isPortrait = false;
   function updateOrientation() {
     isPortrait = window.innerHeight > window.innerWidth;
   }
   ```

2. **起動時に1回呼び、`resize` のリスナでも呼ぶこと。**
   既存の `window.addEventListener('resize', setupCanvas)` と**併せて**呼ぶ形でよい。

3. **`update(dt)` の先頭で、`isPortrait` が `true` なら何もせずに `return` する。**
   縦画面の間はゲームを進めない（タイムが進んだり、気づかないうちに死んだりしないため）。

   ```js
   function update(dt) {
     if (isPortrait) return;   // 縦画面の間はゲームを止める
     …
   }
   ```

4. **`render()` の最後（仮想パッドを描いたあと）で、`isPortrait` が `true` なら `drawRotateNotice(ctx)` を呼ぶ。**
   これですべての画面（タイトル・プレイ・ポーズ）の上に案内が出ます。

**PC でウィンドウを縦長にした場合も同じ案内が出ますが、それで構いません。**

### 5. 技術的な特徴

**このゲームの作り方の特徴を、簡潔に書くこと。**

- **画像ファイルを1枚も使っていない。** ヤギ・敵・地形・背景のすべてを Canvas のパス描画で生成している
- ヤギは関節を持つ骨格として実装され、足を置く位置から膝の角度を逆算している（そのため、走る速度に応じて歩幅と歩数が変わり、接地した足は地面を滑らない）
- 外部ライブラリを一切使っていない（Vanilla JavaScript + Canvas 2D のみ）。ビルド作業も不要
- 固定タイムステップで物理を更新しているため、フレームレートが変動しても挙動が変わらない
