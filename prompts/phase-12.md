# 作業A — 地形タイルの色をステージごとに変える

## A-1. `src/config.js` に既定の地形色を追加

現在 `world.js` の `render` に直接書かれている色を、**そのままの値で** config に移す。

```
// ===== 地形タイルの既定色（ステージ側の tilePalette で上書きできる）=====
TILE_ROCK           = '#5a5148'  // 岩の塗り
TILE_ROCK_TOP       = '#7d7266'  // 岩の上端3px
TILE_BREAKABLE      = '#7a6a55'  // 破壊可能岩の塗り
TILE_BREAKABLE_TOP  = '#9a8a72'  // 破壊可能岩の上端3px
TILE_CRACK          = '#4a4038'  // 破壊可能岩のひび
TILE_ONEWAY         = '#8a6b45'  // すり抜け床
TILE_SPIKE          = '#c9ccd1'  // 棘
```

**値は現在の実装と同じものにすること。** 既定のステージ1の見た目は一切変わってはいけません。

## A-2. `src/world.js` の変更

`constructor(stageData)` の中で、**既定色にステージの `tilePalette` を上書きした配色を保持する**。

```js
this.tilePalette = {
  rock: TILE_ROCK, rockTop: TILE_ROCK_TOP,
  breakable: TILE_BREAKABLE, breakableTop: TILE_BREAKABLE_TOP,
  crack: TILE_CRACK, oneway: TILE_ONEWAY, spike: TILE_SPIKE,
  ...(stageData.tilePalette || {}),
};
```

`render` の中でタイルを塗っている箇所を、**すべて `this.tilePalette.○○` を参照するように置き換える**こと。

**タイルの形（矩形の大きさ、上端3px、すり抜け床の帯8px、棘の三角形3つ、ひびの対角線2本）は一切変更しないこと。色の取得元だけを変えます。**

**破片（デブリ）の色は変更しないこと。** 破片は `spawnDebris` の呼び出し側で色を渡す仕組みなので、そこは触りません。

# 作業B — 洞窟テーマの背景（`src/background.js`）

## B-1. `src/config.js` に洞窟用の定数を追加

```
// ===== 洞窟テーマの背景 =====
BG_CAVE_STALACTITE_SPACING = 48   // 氷柱の間隔(px)
BG_CAVE_STALAGMITE_SPACING = 56   // 石筍の間隔(px)
BG_CAVE_FLOOR_HEIGHT       = 70   // 近景の岩床の高さ(px)
BG_CAVE_ICE_SHINE          = 'rgba(255,255,255,0.35)'  // 氷柱のハイライト
```

## B-2. `Background` がテーマを受け取る

```js
constructor(palette, theme) {
  this.theme = theme || 'alpine';
  // …パレットの構築は現在のまま…
  // 形状の生成を、テーマごとに分ける
}
```

**`theme` が `'alpine'`（または未指定）のときは、現在の描画をそのまま使うこと。一切変更しないこと。**

## B-3. `'cave'` テーマの形状（コンストラクタで1回だけ生成すること）

**乱数はコンストラクタでのみ使うこと。`render` の中で `Math.random()` を呼ばないこと。**

すべて幅 `BG_PATTERN_WIDTH`(960px) を1単位として横に繰り返す。

### 層1 — 遠景：奥の岩壁（スクロール係数 `BG_FAR_FACTOR`）

上下から迫る岩をシルエットで描く。

- **上から垂れる岩**: 幅140px間隔で **7個**。各岩は下向きの三角形で、**底辺の幅は100〜160のランダム、高さは80〜200のランダム**。画面上端（y=0）から生やす。
- **下から立ち上がる岩**: 幅160px間隔で **6個**。上向きの三角形で、**底辺の幅は120〜200のランダム、高さは60〜140のランダム**。画面下端（y=`LOGICAL_HEIGHT`）から生やす。
- 塗りは `palette.farFill`、輪郭は `palette.farEdge` の線幅2。

### 層2 — 中景：天井から垂れる氷柱（スクロール係数 `BG_MID_FACTOR`）

**このステージの主役です。氷穴だと一目で分かるようにしてください。**

- `BG_CAVE_STALACTITE_SPACING`(48px) 間隔で **20本**。
- 各氷柱は**下向きの細い三角形**。画面上端（y=0）から生やす。
  **底辺の幅は14〜26のランダム、高さは50〜150のランダム。**
- 塗りは `palette.midFill`。
- **各氷柱に、`BG_CAVE_ICE_SHINE` の線幅2のハイライトを1本引くこと。**
  氷柱の左寄り（底辺の左から1/3の位置）から先端に向かう直線にする。これで「氷」に見えます。
- 上端に、氷柱がぶら下がる**天井の帯**として、y=0 から高さ22px を `palette.midFill` で塗ること。

### 層3 — 近景：石筍と岩床（スクロール係数 `BG_NEAR_FACTOR`）

- 画面下端から高さ `BG_CAVE_FLOOR_HEIGHT`(70px) の帯を `palette.nearFill` で塗る。
- その帯の上端から、`BG_CAVE_STALAGMITE_SPACING`(56px) 間隔で **18本**の**上向きの三角形**（石筍）を生やす。
  **底辺の幅は20〜40のランダム、高さは40〜110のランダム。** 塗りは `palette.nearFill`。

### 空のグラデーション

**テーマに関わらず、現在どおり `palette.skyTop` → `palette.skyBottom` の縦グラデーションを画面全体に描くこと**（スクロールしない）。
洞窟では、これが「奥の暗がり」として機能します。

### 縦方向のスクロール

**現在の `offsetY = -camera.y * factor * 0.5` をそのまま使うこと。**
