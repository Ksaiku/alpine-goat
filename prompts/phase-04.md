### (b) `moveAndCollide(entity, dt, world)` 関数

**ヤギ専用にせず、Phase 8 の敵でも使える汎用関数として作ること。**
`entity` は `x` / `y` / `width` / `height` / `vx` / `vy` / `onGround` を持つ任意のオブジェクトとする。

**★処理は必ず「水平 → 垂直」の順に、軸を分けて解決すること。** 同時に解くと壁にめり込みます。

**手順1: 縦移動の前の足元位置を記録する**
```js
const prevBottom = entity.y + entity.height;
```

**手順2: 水平移動と解決**
```
entity.x += entity.vx * dt

重なる行の範囲 rowFrom..rowTo を求める:
  rowFrom = floor(entity.y / TILE_SIZE)
  rowTo   = floor((entity.y + entity.height - 1) / TILE_SIZE)

vx > 0 のとき（右へ移動中）:
  col = floor((entity.x + entity.width - 1) / TILE_SIZE)
  rowFrom..rowTo のいずれかが isSolid なら:
    entity.x = col * TILE_SIZE - entity.width
    entity.vx = 0

vx < 0 のとき（左へ移動中）:
  col = floor(entity.x / TILE_SIZE)
  rowFrom..rowTo のいずれかが isSolid なら:
    entity.x = (col + 1) * TILE_SIZE
    entity.vx = 0
```
**すり抜け床（`=`）は水平方向では衝突させないこと。**

**手順3: 垂直移動と解決**
```
entity.y += entity.vy * dt
entity.onGround = false

重なる列の範囲 colFrom..colTo を求める:
  colFrom = floor(entity.x / TILE_SIZE)
  colTo   = floor((entity.x + entity.width - 1) / TILE_SIZE)

vy > 0 のとき（落下中）:
  row = floor((entity.y + entity.height - 1) / TILE_SIZE)
  colFrom..colTo のいずれかについて、次のどちらかが成り立てば着地:
    ・isSolid(col, row) が true
    ・isOneWay(col, row) が true かつ prevBottom <= row * TILE_SIZE
      （＝移動前の足元が、その床の上面より上にあった場合だけ乗る）
  着地したら:
    entity.y = row * TILE_SIZE - entity.height
    entity.vy = 0
    entity.onGround = true

vy < 0 のとき（上昇中）:
  row = floor(entity.y / TILE_SIZE)
  colFrom..colTo のいずれかが isSolid なら（**すり抜け床は無視**）:
    entity.y = (row + 1) * TILE_SIZE
    entity.vy = 0
```

### `render(ctx)` の描画仕様

画面内に見えているタイルだけを描く（Phase 5 のカメラ導入に備えた作りにしておくとよいが、今は全タイル走査でよい）。

| 記号 | 描き方 |
|---|---|
| `#` 岩 | 32×32 を `#5a5148` で塗り、上端3pxだけ `#7d7266` で塗る |
| `*` 破壊可能岩 | 32×32 を `#7a6a55` で塗り、上端3pxを `#9a8a72`、さらに中央に `#4a4038` の線でひび（対角に2本）を描く |
| `=` すり抜け床 | タイル**上端から高さ8pxの帯だけ**を `#8a6b45` で塗る（残りは描かない） |
| `^` 棘 | タイル幅を3等分し、`#c9ccd1` の上向き三角形を3つ描く（底辺はタイル下端） |
| `.` | 何も描かない |
