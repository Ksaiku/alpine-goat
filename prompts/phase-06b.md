# 作業A — 接地した足が滑る問題を完全に解消する

## あなたの分析は正しい

指摘のとおり、接地期に `distance` が `0.6 × 62 = 37.2px` 進むのに対し、足先の掃引量が `2 × stride`（最大 28.6px）しかないため差分が滑りになります。

## 解決策：1サイクルの距離を歩幅から逆算する

`GOAT_STEP_LENGTH` を固定値にするのをやめ、**歩幅から1サイクルの距離を計算**します。

滑りゼロの条件は次のとおりです。

```
接地期に体が進む距離        = GOAT_STANCE_RATIO × stepLength
接地期に足先が後ろへ動く距離 = 2 × stride
この2つが等しければ滑らない  →  stepLength = 2 × stride / GOAT_STANCE_RATIO
```

歩幅が速度で変わると `stepLength` も変わるため、`距離 ÷ stepLength` で位相を計算すると速度変化の瞬間に位相が飛びます。
**そこで、位相そのものを毎フレーム積み上げます。**

この方式なら、**歩幅も歩調（1秒あたりの歩数）も速度に応じて増え、かつ滑りが完全にゼロ**になります。

## A-1. `src/config.js` の変更

**`GOAT_STEP_LENGTH` を削除**し、代わりに以下を追加する。

```
GOAT_STRIDE_MIN   = 8      // 歩幅の下限(px)
GOAT_STRIDE_MAX   = 16     // 歩幅の上限(px)
GOAT_STRIDE_SCALE = 0.031  // 速度(px/s)から歩幅への係数
GOAT_LIFT_MIN     = 2      // 足を持ち上げる高さの下限(px)
GOAT_LIFT_MAX     = 9      // 足を持ち上げる高さの上限(px)
GOAT_LIFT_SCALE   = 0.030  // 速度から持ち上げ高さへの係数
GOAT_STANCE_RATIO = 0.6    // 1サイクルのうち足が地面についている割合
```

## A-2. `src/goat.js` の変更

**`distance` プロパティを削除**し、代わりに `phase`（初期値 `0`）、`stride`、`lift` を持たせる。
`update()` の**手順8の後**（`animTime` などの更新と同じ場所）で、次のとおり計算する。

```js
const speed = Math.abs(this.vx);
// 歩幅と持ち上げ高さは速度に応じて変える
this.stride = Math.min(GOAT_STRIDE_MAX,
                       Math.max(GOAT_STRIDE_MIN, GOAT_STRIDE_MIN + speed * GOAT_STRIDE_SCALE));
this.lift   = Math.min(GOAT_LIFT_MAX,
                       Math.max(GOAT_LIFT_MIN,   GOAT_LIFT_MIN   + speed * GOAT_LIFT_SCALE));
// 接地した足が滑らない、1サイクルぶんの移動距離
const stepLength = 2 * this.stride / GOAT_STANCE_RATIO;
// 位相は「距離÷サイクル長」ではなく、毎フレーム積み上げる（速度変化で位相が飛ばない）
if (this.onGround) {
  this.phase = (this.phase + (speed * dt) / stepLength) % 1;
}
```

## A-3. `src/goatRenderer.js` の変更

- `phase` / `stride` / `lift` を**レンダラ内で計算するのをやめ**、`goat.phase` / `goat.stride` / `goat.lift` を読むだけにする。
- 接地期・遊脚期の判定に使う `0.6` は `GOAT_STANCE_RATIO` を参照する。
- 足先の位置の計算式そのものは**変更しない**（`stride` の掛け方も現状のまま）。

# 作業C — 細部の調整（あなたの指摘への対応）

## C-1. 尾を大きくする

> 「尾が小さすぎて目立たない（長さ12）」

**長さ16、付け根の幅6、先端の幅2** に変更する。向き（上後方へ跳ね上げる）は現状のまま。

## C-2. 呼吸を見えるようにする

> 「呼吸の上下動（±0.8px）はほぼ視認不可」

`idle` 状態の胴体の上下動を **`Math.sin(goat.animTime * 2) * 2.0`** に変更する（振幅 0.8 → **2.0**）。

## C-3. ジャンプ姿勢の前脚をもっと伸ばす

> 「ジャンプ姿勢の『前脚を前へ伸ばす』感が弱い」

`jump` 状態の足先の目標を次に変更する。

| 脚 | 変更前 | **変更後** |
|---|---|---|
| 前脚 | `footX = baseX + 12, footY = -10` | **`footX = baseX + 18, footY = -8`** |
| 後脚 | `footX = baseX - 8, footY = -14` | **`footX = baseX - 12, footY = -18`** |

前脚をより前へ・低めに伸ばし、後脚をより後ろへ・高く畳むことで、跳躍のシルエットを強めます。

## C-4. 膝が外へ張り出すフレームをなくす

> 「足先が付け根に近いときの `d` クランプの影響で、膝が外側に張り出す」

膝を求める計算で、`d` の**下限を大きくする**。

```js
// 変更前: d = Math.min(Math.max(d, Math.abs(L1 - L2) + 0.01), L1 + L2 - 0.01);
// 変更後:
d = Math.min(Math.max(d, (L1 + L2) * 0.5), L1 + L2 - 0.01);
```

上腿と下腿が同じ長さのため、変更前の下限は実質 0 でした。その結果、足先が付け根に近づくと脚が極端に折り畳まれて膝が大きく飛び出します。
**下限を「脚を伸ばしきった長さの半分」にすることで、膝の曲がりが物理的にありえる範囲に収まります。**

## C-5. 奥の脚の横ずらしは維持

あなたが独自に入れた「奥の脚に -2px の横オフセット」は**良い判断です。そのまま維持してください。**
