# 作業B — ヤギのプロシージャル描画

## 設計方針

**画像は一切使わず、Canvas のパス描画だけでヤギを描きます。**
スプライトのコマを切り替えるのではなく、**関節の角度を計算して、その角度から体の各部位を描く**方式です。これにより、走行速度に応じて歩幅が変わる、着地で脚が沈むといった連続的な動きが自然に出ます。

## B-1. `src/goat.js` への追加

以下の3つのプロパティを追加し、`update()` の**手順8の後**に更新する。

| プロパティ | 初期値 | 更新方法 |
|---|---|---|
| `distance` | `0` | **接地しているときだけ** `this.distance += Math.abs(this.vx) * dt` |
| `animTime` | `0` | 毎フレーム `this.animTime += dt`（待機モーション用） |
| `timeSinceLanded` | `999` | 着地した瞬間（前フレーム非接地→今フレーム接地）に `0` にリセットし、以降 `+= dt` |

**`distance` を「時間」ではなく「移動距離」で持つのが重要です。** 時間で歩行サイクルを回すと、速度が変わったときに足が地面を滑ります。距離で回せば、足の接地点が地面に対して止まります。

`render(ctx)` の中身は**すべて削除**し、`goatRenderer.js` の `renderGoat(ctx, this)` を呼ぶだけにする。

## B-3. `src/goatRenderer.js`（新規作成）

`export function renderGoat(ctx, goat)` を1つだけ公開する。

### 座標系（最重要）

```js
ctx.save();
// 原点をヤギの「足元の中央」に置く
ctx.translate(goat.x + goat.width / 2, goat.y + goat.height);
// 左向きのときは水平反転する（以降は常に「右向き」として描けばよい）
if (goat.facing === -1) ctx.scale(-1, 1);
// …ここで描画…
ctx.restore();
```

**以降のすべての座標は「足元中央が原点、上方向が負のy、右向き」のローカル座標**で書くこと。

### 骨格の基準位置（ローカル座標）

胴体の傾きや上下動を加える前の、基準となる位置です。

| 部位 | 位置 (x, y) |
|---|---|
| 胴体の中心 | `(0, -32)` |
| 前脚の付け根（肩） | `(15, -30)` |
| 後脚の付け根（腰） | `(-17, -30)` |
| 首の付け根 | `(19, -38)` |
| 頭の中心 | `(30, -49)` |
| 尾の付け根 | `(-24, -37)` |

### 脚の仕様

- 各脚は**2本の骨**でできている。**上腿 = 15px、下腿 = 15px**、その先に**蹄 = 5px**。
- 脚は4本。手前の前脚・奥の前脚・手前の後脚・奥の後脚。
- **奥の脚は `GOAT_COLOR_LEG_FAR`、手前の脚は `GOAT_COLOR_LEG` で描く。**
- 線幅は上腿5px、下腿4px、蹄は3px。線の端は丸く（`lineCap = 'round'`）。

#### 2本の骨で足先を目標位置に届かせる計算（必ずこの方法で実装すること）

付け根 `H` と目標の足先 `F` が与えられたとき、膝の位置を次の式で求める。

```js
let dx = F.x - H.x, dy = F.y - H.y;
let d = Math.hypot(dx, dy);
// 届かない/近すぎる場合は範囲内に丸める（ゼロ除算と NaN を防ぐ）
d = Math.min(Math.max(d, Math.abs(L1 - L2) + 0.01), L1 + L2 - 0.01);
const a = (L1 * L1 - L2 * L2 + d * d) / (2 * d);
const h = Math.sqrt(Math.max(0, L1 * L1 - a * a));
const ux = dx / d, uy = dy / d;              // 付け根から足先への単位ベクトル
const mx = H.x + ux * a, my = H.y + uy * a;  // 膝を下ろす基準点
// 垂直方向へ h だけずらしたところが膝。bend が曲がる向き（+1 か -1）
const knee = { x: mx - uy * h * bend, y: my + ux * h * bend };
```

**`bend` の値:**
- **前脚: `bend = -1`（膝が後ろへ出る）**
- **後脚: `bend = +1`（膝が前へ出る）**

これは実際の四足動物の脚の曲がり方です。逆にすると「バッタのような不自然な脚」になります。

#### 足先の目標位置（歩行サイクル）

**位相（0〜1）の求め方:**
```js
const phase = (goat.distance / GOAT_STEP_LENGTH) % 1;
```
4本の脚の位相は、対角線の組でそろえる（速歩の足取り）:

| 脚 | 位相 |
|---|---|
| 手前の前脚 | `phase` |
| 奥の後脚 | `phase` |
| 奥の前脚 | `(phase + 0.5) % 1` |
| 手前の後脚 | `(phase + 0.5) % 1` |

**歩幅と持ち上げ高さ（速度に応じて変える）:**
```js
const speed  = Math.abs(goat.vx);
const stride = Math.min(16, Math.max(4, speed * 0.055));  // 前後の振れ幅
const lift   = Math.min(9,  Math.max(1, speed * 0.030));  // 足を持ち上げる高さ
```

**足先の位置（付け根の x を `baseX` として）:**
```js
if (p < 0.6) {
  // 接地期: 足を地面につけたまま後ろへ送る
  const t = p / 0.6;
  footX = baseX + stride - stride * 2 * t;
  footY = 0;
} else {
  // 遊脚期: 持ち上げて前へ振り出す
  const t = (p - 0.6) / 0.4;
  footX = baseX - stride + stride * 2 * t;
  footY = -lift * Math.sin(Math.PI * t);
}
```

### 状態ごとの姿勢

`goat.state` に応じて、胴体の傾き・上下動・脚の扱いを変える。

| state | 胴体の傾き | 胴体の上下 | 脚 |
|---|---|---|---|
| `idle` | 0 | `Math.sin(goat.animTime * 2) * 0.8`（呼吸） | 4本とも足先を `footX = baseX`, `footY = 0` に固定 |
| `walk` / `run` | `-0.05` ラジアン | `Math.sin(phase * Math.PI * 4) * (lift * 0.35)` | 上記の歩行サイクル |
| `jump` | `-0.20` ラジアン（頭が上） | 0 | **前脚は前方へ伸ばす**（`footX = baseX + 12`, `footY = -10`）、**後脚は畳む**（`footX = baseX - 8`, `footY = -14`） |
| `fall` | `+0.12` ラジアン（頭が下） | 0 | 4本とも下へ伸ばす（`footX = baseX`, `footY = 4`） |

**着地の沈み込み（必ず実装すること）:**
`goat.timeSinceLanded < 0.18` のとき、沈み込み量を
```js
const squash = (1 - goat.timeSinceLanded / 0.18) * 6;
```
として、**胴体・首・頭のy座標をすべて `+squash` だけ下げる**（足先は下げない）。これにより着地で脚が曲がって体が沈む動きになります。

胴体の傾きは、胴体・首・頭・尾を描く前に `ctx.rotate(傾き)` を胴体中心まわりにかけて実現してよい。**ただし脚の付け根の位置も傾きに合わせてずらすこと**（体だけ回って脚が取り残されないように）。

### 描画の順序（必ずこの順で描くこと）

1. 奥の後脚 → 奥の前脚（`GOAT_COLOR_LEG_FAR`）
2. 尾
3. 胴体
4. 毛のストローク
5. 手前の後脚 → 手前の前脚（`GOAT_COLOR_LEG`）
6. 首
7. 頭 → 顎髭 → 耳 → 角 → 目 → 鼻

### 各部位の形

- **胴体**: 幅48 × 高さ28 のなめらかな閉曲線。`bezierCurveTo` を4回つないで描く。前（右）側をやや高く、後ろ（左）側をやや細くする。塗りは**縦方向の線形グラデーション**で、上端 `GOAT_COLOR_BACK` → 下端 `GOAT_COLOR_BELLY`。
- **毛のストローク**: 胴体の下側の輪郭に沿って、長さ4〜8pxの短い線を**18本**、`GOAT_COLOR_FUR` で描く。**位置は毎フレーム同じにすること**（`Math.random()` を使わず、インデックスから計算する）。
- **首**: 首の付け根から頭の中心へ向かう台形。付け根側の幅14、頭側の幅10。塗りは `GOAT_COLOR_BACK`。
- **頭**: 長さ24 × 高さ14 程度の、鼻先が細くなる形。水平から **-15度**（鼻先がやや下）に傾ける。塗りは `GOAT_COLOR_BACK`。
- **顎髭**: 頭の下側後方から下へ垂れる、長さ10前後の細い三角形。`GOAT_COLOR_BELLY`。**ヤギらしさが最も出る部位なので必ず入れること。**
- **耳**: 頭の後方上から斜め後ろ下へ伸びる、長さ11の細い葉形。`GOAT_COLOR_BELLY`。
- **角**: 頭の後方上から**後ろへ湾曲**する曲線を**2本**（手前と奥で3pxずらす）。`quadraticCurveTo` を使い、長さ約20px、線幅4px、`GOAT_COLOR_HORN`。**先端を細くするため、奥の角は線幅3pxにする。**
- **目**: 頭の前寄り上部に半径1.6の円。`GOAT_COLOR_EYE`。
- **鼻**: 鼻先に半径1.4の円。`GOAT_COLOR_NOSE`。
- **尾**: 付け根から**上後方へ**跳ね上がる、長さ12の細い三角形。`GOAT_COLOR_BACK`。（ヤギの尾は上を向いています）
