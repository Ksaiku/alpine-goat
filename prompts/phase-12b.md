# 作業A — 洞窟の天井が開始時に見えない問題

## あなたの指摘

> ステージ2の開始直後は氷柱の「先端だけ」が見えていて、天井そのものは縦スクロールで登らないと現れない。

**そのとおりです。** 原因は縦のパララックス（`offsetY = -camera.y * factor * 0.5`）です。
ステージ2の開始位置では `camera.y` が 228 でクランプされるため中景が約46px上へずれ、**高さ22pxの天井帯が画面の外に出ています。**

## 修正内容

`offsetY` の計算式は**変更しません**（他のテーマに影響するため）。
代わりに、**天井の帯を「画面の上端よりさらに上」から始めて、十分な厚みを持たせます。**

`src/config.js` に追加:

```
BG_CAVE_CEILING_Y      = -80   // 洞窟の天井の帯の上端(px)。画面外から始めて隙間を防ぐ
BG_CAVE_CEILING_HEIGHT = 160   // 洞窟の天井の帯の高さ(px)
```

| 項目 | 現在 | **変更後** |
|---|---|---|
| 天井の帯 | `y = 0` から高さ22 | **`y = BG_CAVE_CEILING_Y` から高さ `BG_CAVE_CEILING_HEIGHT`**（下端は `y = 80`） |
| 氷柱の付け根 | `y = 0` | **`y = 80`**（帯の下端） |

中景が最大46pxずれても**帯の下端が `y = 34` に残り、画面上端が必ず天井で覆われます。**

**氷柱の本数・幅・高さ・ハイライト・石筍・遠景の岩壁は一切変更しないこと。** 付け根の y だけが変わります。

# 作業B — 洞窟の「中にいる」感じを強める（暗がり）

## 発注者の要望

> ステージ2も後ろの背景（山や空といった風景）を氷穴の中にいる感じに変えたい

背景の形（氷柱・石筍・奥の岩壁）は Phase 12 で洞窟になっています。
足りないのは、**「岩に囲まれて視界が閉じている」という感覚**です。

**画面の外周を暗く落とす（周辺減光）**を洞窟テーマだけに追加します。
洞窟の中では光源が乏しく、視界の端が闇に沈みます。これがあるだけで「屋内」に見えます。

## B-1. `src/config.js` に追加

```
BG_CAVE_VIGNETTE_COLOR = 'rgba(3, 8, 14, 0.62)'  // 洞窟の周辺減光の色（外周側）
BG_CAVE_VIGNETTE_INNER = 0.30                    // 減光が始まる半径の割合（0=中心 1=外周）
```

## B-2. `src/background.js` に `renderVignette(ctx)` を追加して `export` する

```js
/**
 * 洞窟テーマのとき、画面の外周を暗く落として「中にいる」感じを出す。
 * それ以外のテーマでは何も描かない。
 * ★ゲームの世界（地形・ヤギ・敵）を描いたあと、HUDを描く前に呼ぶこと。
 */
renderVignette(ctx) {
  if (this.theme !== 'cave') return;
  // …描画…
}
```

**描画の仕様:**

- `ctx.createRadialGradient` で放射状のグラデーションを作る
- 中心は画面の中央（`LOGICAL_WIDTH / 2`, `LOGICAL_HEIGHT / 2`）
- 内側の半径 = `外周までの距離 × BG_CAVE_VIGNETTE_INNER`、外側の半径 = 外周までの距離
  （外周までの距離は、中心から画面の角までの距離 `Math.hypot(LOGICAL_WIDTH/2, LOGICAL_HEIGHT/2)`）
- 内側の色は `'rgba(3, 8, 14, 0)'`（完全に透明）、外側の色は `BG_CAVE_VIGNETTE_COLOR`
- 画面全体を塗る
- **全体を `ctx.save()` / `ctx.restore()` で囲むこと**

## B-3. `src/main.js` から呼ぶ

`render()` の中で、**ゲームの世界を描いたあと（`ctx.restore()` の直後）、HUD を描く前**に呼ぶこと。

```
background.render(ctx, camera)      // 画面座標
ctx.save()
camera.applyTo(ctx)
world.render(ctx, camera)
（敵）
goat.render(ctx)
ctx.restore()
background.renderVignette(ctx)      // ★ここに追加（画面座標）
（HUD・デバッグ）
Input.renderTouchControls(ctx)
```

**ポーズ画面やクリア画面のオーバーレイより前に描くこと。** メニューのパネルの上に暗がりが乗ってはいけません。

# 作業C — 山頂テーマ `'summit'` の追加（`src/background.js`）

## 設計方針

**「森林限界を超え、雲海の上に出た夕暮れの山頂」**という絵にします。**木は一本も描きません。**

`'alpine'` と `'cave'` と同じ仕組みで、3層すべてを新しい形状に差し替えます。
**形状の生成はコンストラクタで1回だけ行い、`render` の中で `Math.random()` を呼ばないこと。**

## C-1. `src/config.js` に追加

```
// ===== 山頂テーマの背景 =====
BG_SUMMIT_PEAK_BASE     = 190   // 遠景：遠い峰の稜線の基準の高さ(px)
BG_SUMMIT_PEAK_AMP      = 80    // 遠景：稜線の振れ幅(±)
BG_SUMMIT_CLOUD_BASE    = 330   // 中景：雲海の水面の高さ(px)
BG_SUMMIT_CLOUD_SPACING = 70    // 中景：雲のふくらみの間隔(px)
BG_SUMMIT_SPIRE_SPACING = 96    // 近景：岩峰の間隔(px)
BG_SUMMIT_SPIRE_BASE    = 470   // 近景：岩峰の根元の高さ(px)
```

## C-2. 各層の形状（幅 `BG_PATTERN_WIDTH`(960px) を1単位として横に繰り返す）

### 層1 — 遠景：雲海の向こうに覗く峰（係数 `BG_FAR_FACTOR`）

**`'alpine'` の雪山と同じ作り方**でよいが、基準線と振れ幅だけ変える。

- 0〜960px を16分割した**17点**の高さ配列。各点は `BG_SUMMIT_PEAK_BASE ± ランダム BG_SUMMIT_PEAK_AMP`
- **17点目は1点目と同じ値にすること**（継ぎ目対策）
- 折れ線で結び、その下を「画面下端+200px」まで `palette.farFill` で塗る。稜線は `palette.farEdge` の線幅2

### 層2 — 中景：雲海（係数 `BG_MID_FACTOR`）

**このステージの主役です。「雲の海の上に立っている」と一目で分かるようにしてください。**

- `BG_SUMMIT_CLOUD_BASE`(330px) を雲海の「水面」とし、**そこから画面下端+200px までを `palette.midFill` で塗りつぶす。**
- 水面の上端に、**雲のふくらみ**を並べる。`BG_SUMMIT_CLOUD_SPACING`(70px) 間隔で **14個**。
  各ふくらみは**半円**（`ctx.arc` の上半分）。**半径は 26〜52 のランダム**、中心の y は水面の高さ。塗りは `palette.midFill`。
- さらに、**雲海の水面より少し上に、ちぎれ雲を6個**浮かべること。
  横長の楕円（`ctx.ellipse`）で、**横半径 30〜70 / 縦半径 7〜14 のランダム**、
  y は `BG_SUMMIT_CLOUD_BASE - 20` から `- 90` の範囲でランダム、x は 0〜960 のランダム。
  塗りは `palette.midFill` に**不透明度 0.7** をかけて描く（`ctx.globalAlpha = 0.7`）。

> **ふくらみとちぎれ雲の両方を入れるのが重要です。** 水面だけだと「霧のかかった地面」に見えてしまいます。

### 層3 — 近景：逆光で黒く沈んだ岩峰（係数 `BG_NEAR_FACTOR`）

- `BG_SUMMIT_SPIRE_BASE`(470px) から「画面下端+200px」までを `palette.nearFill` で塗る。
- その上端から、`BG_SUMMIT_SPIRE_SPACING`(96px) 間隔で **11本**の**鋭い上向き三角形**を生やす。
  **底辺の幅は40〜80のランダム、高さは90〜200のランダム。** 塗りは `palette.nearFill`。

> **`'cave'` の石筍より、細く高くすること。** 切り立った峰に見せるためです。

## C-3. 空のグラデーション

**テーマに関わらず、現在どおり `palette.skyTop` → `palette.skyBottom` の縦グラデーションを画面全体に描くこと**（スクロールしない）。
夕暮れの空は、この層が担います。
