# 作業A — 突進後の「つんのめり」を解消する

## あなたの指摘

> 突進終了後の減速が急: 620→260 に瞬間で落ちるため、突進直後に「つんのめる」ような停止感がある
> 突進の距離が短く感じる: `620 × 0.26 ≈ 161px`（約5タイル）

**2つとも同じ原因です。まとめて解決します。**

`DASH_DURATION` を伸ばすのではなく、**「最高速を超えている間は、瞬間的に切り詰めず、なめらかに落とす」**という一般則に変えます。
こうすると突進の勢いが自然に尾を引き、**距離も伸びて、かつ段差もなくなります。**

## A-1. `src/config.js` に1つ追加

```
OVERSPEED_DECEL = 1800   // 最高速を超えている間の減速度(px/s^2)。突進の勢いを尾を引かせて逃がす
```

## A-2. `src/goat.js` 手順2（水平入力）の書き換え

現在は「加速してから最高速で切り詰める」ですが、これを次に変更する。

```js
// 突進中はこのブロックごとスキップする（既存のとおり）
const dir = (Input.isDown('right') ? 1 : 0) + (Input.isDown('left') ? -1 : 0);

if (dir !== 0) {
  // すでに最高速以上で同じ向きに進んでいるときは、それ以上加速しない
  const sameDir = Math.sign(this.vx) === dir;
  if (!(sameDir && Math.abs(this.vx) >= MOVE_SPEED)) {
    const accel = this.onGround ? ACCEL_GROUND : ACCEL_AIR;
    this.vx += dir * accel * dt;
  }
}

// 最高速を超えている間は、切り詰めずになめらかに最高速まで落とす
const sp = Math.abs(this.vx);
if (sp > MOVE_SPEED) {
  this.vx = Math.sign(this.vx) * Math.max(MOVE_SPEED, sp - OVERSPEED_DECEL * dt);
}

// 入力なし かつ 接地 かつ 最高速以下 のときだけ摩擦をかける
if (dir === 0 && this.onGround && Math.abs(this.vx) <= MOVE_SPEED) {
  const drop = FRICTION_GROUND * dt;
  if (this.vx > 0) this.vx = Math.max(0, this.vx - drop);
  else if (this.vx < 0) this.vx = Math.min(0, this.vx + drop);
}
```

## A-3. 突進終了時の速度の丸め込みを**削除**する

```js
// 削除する:
// if (Math.abs(this.vx) > MOVE_SPEED) this.vx = Math.sign(this.vx) * MOVE_SPEED;
```

**`isDashing = false` と `dashCooldown = DASH_COOLDOWN` はそのまま残すこと。**
速度は A-2 の仕組みが 0.2 秒かけて 620 → 260 に落とします。

### 期待される結果（実装後に確認してください）

- 突進の実質的な到達距離: 161px → **約249px（約7.8タイル）**
- 減速にかかる時間: 瞬間 → **0.2秒**
- 通常走行時の最高速は **260 ちょうどのまま変わらない**（加速と減速が釣り合うよう設計しています）

### (b) 挙動

**マーモット / ヤマアラシ（地上を往復）**

```
速度は type ごとの定数。vx = facing * 速度
重力を適用し、moveAndCollide(this, dt, world) で地形と衝突させる

反転する条件（どちらか）:
  ・壁にぶつかって vx が 0 になった
  ・進行方向の足元に地面がない（崖の端）
     判定: col = Math.floor((facing === 1 ? x + width + 2 : x - 2) / TILE_SIZE)
           row = Math.floor((y + height + 2) / TILE_SIZE)
           world.isSolid(col, row) が false なら反転
反転したら facing を反転させ、その場で vx = facing * 速度 に設定し直す
```

**ワシ（空中）**

```
重力なし・地形との衝突なし
this.baseY（出現時の y）と this.spawnX（出現時の x）を保持しておく
this.time += dt

x += facing * ENEMY_EAGLE_SPEED * dt
y = this.baseY + ENEMY_EAGLE_AMPLITUDE * Math.sin(this.time * Math.PI * 2 / ENEMY_EAGLE_PERIOD)

x が spawnX から ENEMY_EAGLE_RANGE 以上離れたら facing を反転する
```

### (d) 当たり判定の解決関数を `export` する

```js
export function resolveGoatEnemyCollisions(goat, enemies, world, onGoatHit)
```

各敵について、`alive` なものだけを対象に、ヤギの当たり判定と AABB で重なりを調べる。
重なっていたら、**次の順序で判定すること**（順序が変わると挙動が変わります）。

**1. 突進中なら撃破**
```
goat.isDashing === true
→ enemy.alive = false
  world.spawnDebris(敵の中心x, 敵の中心y, その敵の体の色, 8)
  ヤギは止めない（速度を変えない）
```

**2. 踏みつけ成立なら撃破**
```
次の3つをすべて満たす:
  ・enemy.stompable === true
  ・goat.vy > 0（落下中）
  ・(goat.y + goat.height) - enemy.y <= STOMP_TOLERANCE
    （ヤギの足元が、敵の上端から STOMP_TOLERANCE(16px) 以内）
→ enemy.alive = false
  world.spawnDebris(敵の中心x, 敵の中心y, その敵の体の色, 8)
  goat.vy = STOMP_BOUNCE
```

**3. それ以外は被弾**
```
→ onGoatHit() を呼ぶ（コールバック）
```

> **設計方針:** SPEC 第7章のとおり、1発死のゲームなので**踏みつけ判定は寛容側に倒します。**
> `STOMP_TOLERANCE` を狭めたり、条件を厳しくしたりしないこと。
