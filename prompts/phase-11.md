# 作業A — 画面から遠い敵を止める

## なぜ必要か

現在、**すべての敵がステージ開始と同時に動き始めます。** ステージが5倍に長くなったことで、次の2つの問題が起きます。

1. **プレイヤーが到着したときの敵の位置が予測できない。**
   ステージ終盤の敵は、プレイヤーが着く頃には60秒以上も往復を続けています。
   死んでやり直すたびに敵の位置が変わり、**同じ場所で同じ攻略ができません。** これは1発死のゲームでは致命的です。
2. 見えていない敵の計算を毎フレーム行うのは無駄です。

**画面の近くにいる敵だけを動かす**ようにして、両方を解決します。

## A-1. `src/config.js` に追加

```
ENEMY_ACTIVE_MARGIN = 320   // 画面の外側この距離までの敵だけを動かす(px)。10タイル分
```

## A-2. `src/enemies.js` に判定関数を追加して `export` する

```js
/**
 * その敵が「動かすべき範囲」にいるかを返す。
 * 画面の左右に ENEMY_ACTIVE_MARGIN の余裕を持たせた矩形に、敵が少しでも入っていれば true。
 * @returns {boolean}
 */
export function isEnemyActive(enemy, camera) {
  const left  = camera.x - ENEMY_ACTIVE_MARGIN;
  const right = camera.x + camera.viewWidth + ENEMY_ACTIVE_MARGIN;
  return enemy.x + enemy.width >= left && enemy.x <= right;
}
```

**縦方向は判定しないこと。** ステージの高さは768pxで画面（540px）とほぼ同じなので、縦で絞る意味がなく、
高所の敵が止まってしまう事故のほうが怖いためです。

## A-3. `resolveGoatEnemyCollisions` の変更

**引数に `camera` を追加**し、`isEnemyActive(enemy, camera)` が `false` の敵は**当たり判定の対象から外す**こと。

```js
export function resolveGoatEnemyCollisions(goat, enemies, world, camera, onGoatHit)
```

## A-4. `src/main.js` の変更

- 敵の更新を、`isEnemyActive(enemy, camera)` が `true` のものだけに限定する
- 敵の描画も、`isEnemyActive(enemy, camera)` が `true` のものだけにする
- `resolveGoatEnemyCollisions` の呼び出しに `camera` を渡す
- デバッグ表示の `enemies:` を **`enemies: <動いている数>/<生存数>`** に変更する

**敵の生成（`startStage`）や、倒された敵を配列から取り除く処理は変更しないこと。**

# 作業B — 進行度バー（`src/hud.js`）

## なぜ必要か

ステージが9600pxになり、**あとどれくらいでゴールなのかが分からなくなりました。**
画面上端に細いバーを出して、現在地・チェックポイント・ゴールの位置を示します。

## B-1. `drawPlayHud` の引数を拡張

`info` に次を追加して受け取る。

```js
{ stageName, time, deaths,
  progress,     // 0〜1。ヤギの x ÷ ステージの横幅
  checkpoints,  // [{ ratio: 0〜1, reached: boolean }, ...]
  goalRatio,    // 0〜1。ゴールの位置。ゴールが無いステージでは null
}
```

`main.js` 側で、`world` と `goat` から次のように計算して渡すこと。

```js
progress    = Math.min(1, Math.max(0, goat.x / world.widthPx))
checkpoints = world.checkpoints.map(cp => ({ ratio: cp.x / world.widthPx, reached: cp.reached }))
goalRatio   = world.goal ? world.goal.x / world.widthPx : null
```

## B-2. バーの描画仕様

**画面の最上部**に、次の順で描く。

| 要素 | 描き方 |
|---|---|
| 背景 | `x=0, y=0, 幅=LOGICAL_WIDTH, 高さ=5` を `rgba(255,255,255,0.18)` で塗る |
| 進行部分 | 同じ位置に、幅 `LOGICAL_WIDTH * progress` を `UI_ACCENT` で塗る |
| チェックポイント印 | 各 `ratio` の位置に **幅2 × 高さ5** の縦線。到達済みは `UI_ACCENT`、未到達は `rgba(255,255,255,0.55)` |
| ゴール印 | `goalRatio` の位置に **幅3 × 高さ5** の縦線を `#ffffff` で |

## B-3. HUD の文字位置をずらす

バーと重ならないよう、**HUD の文字の開始 y を 14 → 22** に変更すること。
（左マージン16px、行間22px はそのまま）
