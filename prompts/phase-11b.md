# 作業A — 背景をステージごとに切り替える

## A-1. `src/background.js` の変更

`Background` のコンストラクタが、**任意でパレットを受け取れる**ようにする。

```js
/**
 * @param {object} [palette] ステージ固有の配色。省略時は config の既定値を使う
 */
constructor(palette) {
  // 既定値に、渡されたパレットの値を上書きする形で使う
  this.palette = {
    skyTop:     BG_SKY_TOP,
    skyBottom:  BG_SKY_BOTTOM,
    farFill:    BG_FAR_FILL,
    farEdge:    BG_FAR_EDGE,
    midFill:    BG_MID_FILL,
    nearFill:   BG_NEAR_FILL,
    ...(palette || {}),
  };
  // …形状の生成は現在のまま…
}
```

`render` の中で色を使っている箇所を、**すべて `this.palette.○○` を参照するように置き換える**こと。

**変更してよいのは「どこから色を取るか」だけです。**
形状の生成方法・層の数・スクロール係数・タイリング方式・基準線の定数は**一切変更しないこと。**

## A-2. ステージデータのパレット

`stage2.js` と `stage3.js` には、すでに次の形で `palette` が入っています（`stage1.js` にはありません＝既定値を使います）。

```js
palette: {
  skyTop: '#22314a', skyBottom: '#6d84a6',
  farFill: '#dce6f0', farEdge: '#9db0c8',
  midFill: '#2c4650', nearFill: '#252a36',
}
```

# 作業B — ステージ2・3を登録する（`src/main.js`）

## B-1. import と STAGES 配列

```js
import { stage1 } from './stages/stage1.js';
import { stage2 } from './stages/stage2.js';
import { stage3 } from './stages/stage3.js';

const STAGES = [stage1, stage2, stage3];
```

## B-2. `startStage(index)` で背景を作り直す

`Camera` を作り直しているのと同じ場所で、**`Background` も作り直す**こと。

```js
background = new Background(STAGES[index].palette);
```

**`background` を `const` から `let` に変更するのを忘れないこと。**

**注意: `stage1` には `palette` がないので `undefined` が渡ります。**
作業A-1 のとおり `...(palette || {})` としておけば、既定値がそのまま使われます。

## B-3. タイトル画面・ステージ選択画面の背景

タイトルとステージ選択では、**ステージ1の配色（＝既定値）を使うこと。**
起動時に `background = new Background()` を1回作っておき、`startStage` で作り直す形でよい。
