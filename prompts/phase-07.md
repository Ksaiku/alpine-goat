## 0-2. ★脚の骨の長さだけ 15 ではなく 18 にする理由

**ここだけ Phase 6 の値（15+15=30）に戻しません。設計上の理由があります。**

脚の**見た目の長さ**は「付け根の高さ（30px）」で決まります。骨を長くしても脚は長く見えません。**膝が曲がるだけです。**
一方、骨が短すぎると足先が目標位置に届かず、**骨が引き伸びて破綻します。**

実際に計算しました（付け根の高さ30、歩幅16のとき、付け根から足先までの距離は34.0px 必要）。

| 骨の長さ | 直立時の膝の張り出し | 歩幅16で足が届くか |
|---|---|---|
| 15 + 15 = 30 | 0.0px（棒のようにまっすぐ） | **届かない（骨が伸びる）** |
| 17 + 17 = 34 | 8.0px | ぎりぎり届く |
| **18 + 18 = 36** | **9.9px** | **余裕をもって届く** ← これを採用 |
| 20 + 20 = 40（現在） | 13.2px | 届く |

**つまり「ずんぐりむっくりの見た目はそのまま、膝だけ自然に曲がる」状態になります。**
Phase 6 では実は足が届いておらず骨が伸びていました。そこだけ直します。

# 作業B — 頭突き（突進）の挙動

## B-1. `src/goat.js` に追加するプロパティ

| プロパティ | 初期値 | 意味 |
|---|---|---|
| `isDashing` | `false` | 突進中か |
| `dashTimer` | `0` | 突進の残り時間（秒） |
| `dashCooldown` | `0` | 再発動できるまでの残り時間（秒） |
| `dashStartedInAir` | `false` | 空中で発動したか（終了判定に使う） |

## B-2. `update(dt)` への組み込み（処理順序を厳守すること）

### 手順1（タイマー減算）に追加

```js
this.dashCooldown = Math.max(0, this.dashCooldown - dt);
if (this.isDashing) this.dashTimer = Math.max(0, this.dashTimer - dt);
```

### 手順2（水平入力）の直前に「突進の開始判定」を入れる

```js
// 発動条件: 突進キーが押された かつ 突進中でない かつ クールダウンが終わっている
if (Input.wasPressed('dash') && !this.isDashing && this.dashCooldown <= 0) {
  this.isDashing = true;
  this.dashTimer = DASH_DURATION;
  this.dashStartedInAir = !this.onGround;
  this.vx = this.facing * DASH_SPEED;
  this.vy = 0;   // 空中で撃っても水平に突っ込むよう、縦速度を消す
}
```

### 手順2（水平入力）を条件分岐にする

**`isDashing` が `true` の間は、水平入力の処理を丸ごとスキップする**（加速も摩擦もかけない）。
`vx` は突進開始時の値を保ち続けます。

### 手順3（ジャンプ）

**突進中もジャンプは可能**とする。既存の処理をそのまま通す。

### 手順4（重力）を条件分岐にする

```js
const gravityScale = this.isDashing ? DASH_GRAVITY_SCALE : 1;
this.vy += GRAVITY * gravityScale * dt;
```

### 手順5（`moveAndCollide`）の**直前**に「破壊可能岩の破壊判定」を入れる

**必ず衝突解決の前に行うこと。** 後に置くと、壁に阻まれて止まってから壊すことになり、1フレーム引っかかります。

```js
if (this.isDashing) {
  world.breakDestructibleAhead(this);
}
```

### 手順6（`moveAndCollide` の後）に「突進の終了判定」を入れる

終了条件は次の**3つのいずれか**。

1. `this.dashTimer <= 0`（持続時間が尽きた）
2. `this.dashStartedInAir === true` かつ `this.onGround === true`（空中で撃って着地した）
3. `this.vx === 0`（壁に衝突して止まった）

終了時の処理:

```js
this.isDashing = false;
this.dashCooldown = DASH_COOLDOWN;
// ★重要: 突進の速度(620)のまま飛び続けないよう、通常の最高速まで落とす
if (Math.abs(this.vx) > MOVE_SPEED) this.vx = Math.sign(this.vx) * MOVE_SPEED;
```

**この速度の丸め込みを忘れないこと。** 忘れると突進後も620で滑走し続け、操作不能に見えます。

### 手順8（状態の更新）

**`isDashing` が `true` のときは、他のどの条件よりも優先して `state = 'dash'` にする。**

### 変更しないこと

- **棘の検出（`touchingSpike`）は突進中も通常どおり動作させる。** 突進は無敵ではありません。
- 落下による復帰処理も通常どおり。

## B-3. `src/world.js` への追加

### (a) `breakDestructibleAhead(entity)` メソッド

進行方向側の**隣の列**を調べ、entity と重なる行に `*` があれば破壊する。

```
facing が +1 のとき: col = Math.floor((entity.x + entity.width) / TILE_SIZE)
facing が -1 のとき: col = Math.floor((entity.x - 1) / TILE_SIZE)

rowFrom = Math.floor(entity.y / TILE_SIZE)
rowTo   = Math.floor((entity.y + entity.height - 1) / TILE_SIZE)

rowFrom から rowTo の各行について、そのタイルが '*' なら:
  ・グリッドの値を '.' に書き換える
  ・そのタイル位置に破片を発生させる
```

**`entity.facing` を参照します。** 汎用性のため、`facing` を持たないオブジェクトが渡された場合は何もしないこと。

### (b) 破片（デブリ）

`World` に `debris` という配列を持たせ、次の3つのメソッドを追加する。

| メソッド | 仕様 |
|---|---|
| `spawnDebris(col, row)` | そのタイルの中心から**8個**の破片を発生させる |
| `updateDebris(dt)` | 破片を更新し、寿命が尽きたものを配列から取り除く |
| `renderDebris(ctx)` | 破片を描画する |

**破片1個のデータ:** `x` / `y` / `vx` / `vy` / `life`（残り寿命・秒）/ `size`

**発生時の値:**
- 位置はタイル中心 ± 10px（**`Math.random()` を使ってよい。発生は1回きりのイベントなので毎フレーム変わりません**）
- `vx` は -140〜+140 のランダム、`vy` は -260〜-60 のランダム
- `life` は 0.5〜0.9 のランダム
- `size` は 3〜6 のランダム

**更新:** `vy += GRAVITY * 0.6 * dt`、`x += vx*dt`、`y += vy*dt`、`life -= dt`。地形との衝突判定は**不要**（貫通してよい）。

**描画:** 破壊可能岩と同じ色 `#7a6a55` の正方形。`life` が 0.25 を切ったら `globalAlpha` を `life / 0.25` にしてフェードアウトさせる。**`save()`/`restore()` で囲むこと。**
