# 作業C — `src/camera.js`

`Camera` クラスを `export` する。

| メンバ | 仕様 |
|---|---|
| `constructor(viewWidth, viewHeight, world)` | 視界の大きさと、クランプに使う world を保持 |
| `x` / `y` | カメラが映している範囲の**左上のワールド座標** |
| `viewWidth` / `viewHeight` | 視界の大きさ（world.render のカリングから参照する） |
| `follow(target, dt)` | 追従処理 |
| `snapTo(target)` | スムージングなしで即座に目標位置へ移動（起動時・復帰時に使う） |
| `applyTo(ctx)` | `ctx.translate(-Math.round(this.x), -Math.round(this.y))` |

### `follow(target, dt)` の処理（この順序で実装すること）

**手順1. 追いたい点を求める**（ヤギの中心 + 進行方向への先読み）

```js
const cx = target.x + target.width  / 2 + target.facing * CAMERA_LOOKAHEAD;
const cy = target.y + target.height / 2;
```

**手順2. デッドゾーンを考慮した目標位置を求める**

```js
let targetX = this.x;
let targetY = this.y;
const relX = cx - (this.x + this.viewWidth  / 2);   // カメラ中心からのずれ
const relY = cy - (this.y + this.viewHeight / 2);
if (relX >  CAMERA_DEADZONE_X) targetX = this.x + (relX - CAMERA_DEADZONE_X);
if (relX < -CAMERA_DEADZONE_X) targetX = this.x + (relX + CAMERA_DEADZONE_X);
if (relY >  CAMERA_DEADZONE_Y) targetY = this.y + (relY - CAMERA_DEADZONE_Y);
if (relY < -CAMERA_DEADZONE_Y) targetY = this.y + (relY + CAMERA_DEADZONE_Y);
```

**手順3. なめらかに寄せる**（フレームレートに依存しない指数補間）

```js
const t = 1 - Math.exp(-CAMERA_SMOOTHING * dt);
this.x += (targetX - this.x) * t;
this.y += (targetY - this.y) * t;
```

**手順4. ステージ外が見えないようクランプする**

```js
const maxX = Math.max(0, this.world.widthPx  - this.viewWidth);
const maxY = Math.max(0, this.world.heightPx - this.viewHeight);
this.x = Math.min(Math.max(this.x, 0), maxX);
this.y = Math.min(Math.max(this.y, 0), maxY);
```

`Math.max(0, ...)` を必ず入れること。ステージが画面より小さい場合に上限が負になり、クランプが壊れるためです。

`snapTo(target)` は、手順1で求めた `cx, cy` にカメラ中心を直接合わせ、手順4のクランプだけを行う（**手順2のデッドゾーンと手順3のスムージングは行わない**）。

# 作業D — `src/background.js`

`Background` クラスを `export` する。

| メンバ | 仕様 |
|---|---|
| `constructor()` | 3層の形状を**1回だけ**生成して配列に保存する |
| `render(ctx, camera)` | 背景を描画する |

### 重要な設計方針

**形状はコンストラクタで1回だけ生成し、以降は使い回すこと。**
`render` の中で `Math.random()` を呼ぶと、毎フレーム山の形が変わってちらつきます。

### 各層の形状（すべて幅 `BG_PATTERN_WIDTH`(960px) を1単位として横に繰り返す）

**層1 — 遠景：雪山**

- 0〜960px を16分割した**17点**の高さ配列を作る（間隔60px）。
- 各点の高さは `300 ± ランダム70`（つまり 230〜370 の範囲）。
- **17点目の高さは1点目と同じ値にすること。** 繰り返しの継ぎ目で稜線が途切れるのを防ぐためです。
- 折れ線で結び、その下を「画面下端 + 200px」まで `BG_FAR_FILL` で塗る。稜線は `BG_FAR_EDGE` の2px線。

**層2 — 中景：針葉樹林**

- 48px間隔で**20本**の木を配置。
- 各木は二等辺三角形。高さは `60〜110` のランダム、底辺の幅は `36`。
- 木の底辺の y は `400` で固定。「y=400 から画面下端 + 200px」までを `BG_MID_FILL` で塗りつぶす。
- 木も `BG_MID_FILL` で塗る（シルエット）。

**層3 — 近景：岩肌**

- 0〜960px を8分割した**9点**の高さ配列（間隔120px）。高さは `470 ± ランダム40`。
- **9点目は1点目と同じ値にすること。**
- 折れ線の下を「画面下端 + 200px」まで `BG_NEAR_FILL` で塗る。

### `render(ctx, camera)` の描画手順

1. **空のグラデーション**を画面全体に描く（`BG_SKY_TOP` → `BG_SKY_BOTTOM` の縦方向の線形グラデーション）。**この層はスクロールさせない。**
2. 遠景 → 中景 → 近景 の順に、以下の方法で描く。

```js
// 横方向：カメラ位置に係数を掛けてずらし、パターン幅で折り返す
const offsetX = -((camera.x * factor) % BG_PATTERN_WIDTH);
// 縦方向：控えめに動かす（係数をさらに半分にする）
const offsetY = -camera.y * factor * 0.5;
// 画面を覆うため3回繰り返して描く
for (let i = 0; i < 3; i++) {
  drawLayer(ctx, offsetX + i * BG_PATTERN_WIDTH, offsetY);
}
```

**背景は「画面座標」で描くこと。** カメラの `applyTo` を適用する**前**に描画します。
